# -Term-Deposit-Subscription-Prediction-Bank-Marketing-
Banks conduct marketing campaigns to promote financial products such as term deposits. However, not every customer subscribes to the offered product. Predicting which customers are more likely to subscribe can help banks reduce marketing costs and improve campaign effectiveness.
Objective
The objective of this project is to build a machine learning model that predicts whether a customer will subscribe to a term deposit based on customer information and previous marketing campaign data.
The project also aims to:
•	Analyze customer behavior 
•	Compare classification algorithms 
•	Evaluate model performance 
•	Use Explainable AI (SHAP/LIME) for prediction interpretation
The project successfully developed machine learning models to predict term deposit subscriptions using customer and campaign data.
Among the tested models:
•	Random Forest performed better than Logistic Regression 
•	SHAP explanations improved model transparency 
•	Dashboard visualizations enhanced business understanding 
Key Insights
•	Customers with longer call durations were more likely to subscribe. 
•	Previous successful marketing outcomes increased future subscription probability. 
•	Financial status and account balance strongly influenced customer decisions. 
•	Random Forest provided higher predictive accuracy and better feature interpretation. 
Business Impact
This system can help banks:
•	Target potential customers more effectively 
•	Reduce unnecessary marketing costs 
•	Improve campaign success rates 
•	Make data-driven business decisions
